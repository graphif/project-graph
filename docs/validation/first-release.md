# 首版验收方案

状态：全部待执行。文档检查不等于产品验收；本轮未启动 Godot、测试或构建。

## 准备

使用副本建立有效旧格式样例、中文与英文材料、嵌套容器、内部/外部连线，以及未知类型/字段、重复 ID、损坏引用和不支持版本的异常样例。异常文件只在受控副本上准备，Godot 项目资源操作遵守 MCP 规则。

首批真实任务使用本仓库调研材料，问题可设为“编辑器是否应该默认自动布局”。录入约 10–15 份来源，包含支持、反例和待解决问题。样例数量不代表产品容量指标。

## 自动检查建议（尚未授权执行）

针对真实行为补充保存往返、加载拒绝不破坏当前内容、保存失败保留原件、复制引用一致性、事务撤销，以及搜索和导出内容覆盖。通过已有最高层稳定入口测试，避免测试私有实现细节。目标平台分别验证文件替换，不以开发机结果外推。

## 结果记录格式

每次记录：验收编号、代码提交与工作区差异、系统/Godot 版本、样例、操作、预期、实际、通过/失败/未执行、失败证据与修复提交。未执行不得填通过。

完整性通过后，再记录证据查找时间、几天后解释旧图的困难及重复录入量。这些产品观察帮助调整范围，不把少量试用写成普遍效率提升。
