# 首版验收方案

状态：首版 A1–A9 与完整人工 UI 验收待执行。已授权完成的内置主题专项检查见 [主题验证记录](theme-palette.md)，不代表首版产品验收完成。

## 准备

使用副本建立有效旧格式样例、中文与英文材料、嵌套容器、内部/外部连线，以及未知类型/字段、重复 ID、损坏引用和不支持版本的异常样例。异常文件只在受控副本上准备，Godot 项目资源操作遵守 MCP 规则。

首批真实任务使用本仓库调研材料，问题可设为“编辑器是否应该默认自动布局”。录入约 10–15 份来源，包含支持、反例和待解决问题。样例数量不代表产品容量指标。

## 由用户执行的手动验收

| 编号 / 需求 | 如何触发 | 应观察到的结果 | 失败时重点检查 |
| --- | --- | --- | --- |
| A1 / R1、R8 | 创建含嵌套、关系与新字段的项目，保存、关闭、重开；另开有效旧文件 | ID、文本、位置、容器、端点、详情和来源保持；旧文件使用新增字段默认值 | 字段遗漏、引用恢复、旧格式默认值 |
| A2 / R2 | 已有未保存文档时打开异常副本 | 清楚报告错误，原件和当前工作内容不被替换或损坏 | 校验是否发生在清空舞台之后、是否静默跳过未知数据 |
| A3 / R1 | 在受控不可写目录保存；授权故障注入后再验证中途写入/替换失败 | 无成功提示、脏状态仍在、上次有效文件可恢复 | 提前清脏、目标截断、临时文件与回退顺序 |
| A4 / R3、R8 | 编辑详情，中文选词确认、换行，分别取消和提交，再撤销重做 | 正文与详情分离，输入法不触发画布命令；一次确认一步撤销 | 焦点、IME、重复提交和快照覆盖 |
| A5 / R4、R8 | 编辑边文字，移动两端、缩放、取消编辑、复制后重开 | 文字随正确连线显示，取消保持原值；复制和保存保留文字 | 标签坐标、端点引用、字段序列化 |
| A6 / R5 | 为节点与边各添来源和摘录，再改详情并尝试打开失效来源 | 摘录保持原文；有效来源可打开，失效时可读摘录且有错误提示 | 证据归属、误覆盖原文、静默错跳 |
| A7 / R6 | 搜索“布局”“引用”、英文及仅存在于详情/边/摘录中的词，定位后返回 | 命中字段明确，节点或关系正确定位，原视野可返回 | 搜索范围、中文短词、索引更新、导航状态 |
| A8 / R8 | 复制嵌套容器，删除、撤销、重做；拖动容器后等待稳定并撤销一次 | 独立副本保留内部关系和新字段；一次操作整体恢复 | ID 映射、外部引用、漏记物理位移、事务串联 |
| A9 / R7 | 选容器导出 Markdown，调整阅读顺序，分别取消和确认；再导出全画布 | 取消不写文件；输出含后代、内部关系、详情和来源，说明外部范围；原图不变 | 选区展开、遗漏证据、顺序不稳定、导出修改原图 |

## 自动检查建议（尚未授权执行）

针对真实行为补充保存往返、加载拒绝不破坏当前内容、保存失败保留原件、复制引用一致性、事务撤销，以及搜索和导出内容覆盖。通过已有最高层稳定入口测试，避免测试私有实现细节。目标平台分别验证文件替换，不以开发机结果外推。

## 结果记录格式

每次记录：验收编号、代码提交与工作区差异、系统/Godot 版本、样例、操作、预期、实际、通过/失败/未执行、失败证据与修复提交。未执行不得填通过。

完整性通过后，再记录证据查找时间、几天后解释旧图的困难及重复录入量。这些产品观察帮助调整范围，不把少量试用写成普遍效率提升。
