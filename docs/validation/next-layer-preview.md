# 提前显示一层标题和连线

缩小后显示最外层当前预览标题、直接下一层小标题及这一层的连接。更深节点与连线隐藏；同一小标题内部的边不展开，相同层间端点的边合并。原有跨组与外部连接保留。预览由 Panel/Label、Line2D/Polygon2D 表达，复用现有圆角、字体、连接曲线和 Godot 节点，不增加依赖。

预览阈值同时考虑当前字体的屏幕尺寸，避免较大分组必须缩得很小才出现标题。显式嵌套框保持真实包含层次；框内普通节点和未分组树优先使用同一区域的 topic_parent，否则只推导单一有向入边的父节点。这样一个平面分组中的深层分支不会全挤成“下一层”。环或多父节点回退到真实包含关系。推导仅用于显示，不写入包含关系或改变拖拽与历史数据。预览标题使用文本首行，超过 48 字时省略；放大或编辑仍显示完整文本。

缓存一层面板、曲线世界几何和圆角采样，离屏预览跳过更新。通过父级画布层遮挡保留物理可见性、原生控件层和字幕 z 顺序；非 CanvasItem 断开的子树及 top_level 子节点单独遮挡并完整恢复。编辑深层节点时临时展开全部祖先；右键样式修改随即更新预览。

使用 Godot MCP 原生读取、脚本修改/创建与编辑器脚本执行。已通过 next_layer_preview_smoke、group_overview_smoke（含实际鼠标点击、双击编辑、编辑取消、存档恢复、级联删除及撤销）、navigation_cache、progressive_loading、canvas_sampling、canvas_antialiasing 和 slice_rounded。大图性能结果见 zoom-border-cache.md；严格稳定 120 Hz 尚未达标。

另通过 preview_documents_smoke：桌面教程操作 1029 对象、教程节点 184 对象、快捷键教程 624 对象及思维导图 1 对象均能加载，四档缩放不改变快照及来源文件 SHA256。已检查生成的原生截图。按分支区分平面分组后的同机基准：局部约 215 FPS、宽范围冷/热约 128/139 FPS，p95 约 11.2/18.1/18.1 ms；冷态仍有约 71 ms 单帧尖峰，不能承诺稳定 120 Hz。

手动验证（安装后的实际操作尚未执行）：在教程操作或快捷键教程中连续缩小。应提前出现大标题、下一层小标题和连线，更深的节点不再堆在预览里；上方未分组的树形分支也应保留分支标题和下一层连接。放大应恢复原文和原线；双击大标题可正常编辑，取消后预览回来。失败时检查漏掉整片树、所有深层标题同时挤出、隐藏节点抢走点击、或缩放改变保存位置。多父或有环的网状关系仍显示普通详情，不能推导出唯一标题层级。
