# 视口边缘的预览标题间距

快捷键教程在 .125 缩放下有两个分组标题同时被固定到视口左上角，出现文字相互覆盖；原裁切只考虑文字矩形，还会把标题背景和色标切掉。

复用 Godot Rect2 和 Transform2D，对当前可见的临时标题背景进行边界裁切和必要的垂直错位，保留其水平关联。不引入全图布局、物理避让或第三方排版库；只处理预览标题，不改动保存对象。计算跟随现有刷新门控，静止画面不重新计算；预览连接在标签定位后更新端点。

Godot MCP 创建并执行 preview_header_spacing_smoke：先在实际教程文件上复现边界裁切和标题相交失败，修复后通过；平移后再次检查，保存快照不变。preview_visual_cleanup、next_layer_preview、progressive_loading 以及四个实文件的四档缩放全部通过，代码 diff --check 通过，已目视检查 /tmp/pg-preview-headers.png。

1029 对象的本次缩放基准平均约 171/123/129 FPS（局部/宽范围冷/热），p95 约 15.0/15.9/13.7 ms；与历史单次数据存在差异，未据此宣称性能提升或严格稳定 120 Hz。

用户手动验收尚未执行：重新打开安装版的快捷键教程，缩小并平移到分组框部分移出窗口的位置。标题背景与色标应完整可见，相邻标题有间距，连线仍指向对应预览块。失败时检查两个标题是否贴边重叠、背景被切掉或标签移动后连接仍留在旧位置。
