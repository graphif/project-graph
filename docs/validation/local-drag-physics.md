# 大图拖动的局部物理验证

2026-10-02 更正：下文原先的拖动 FPS（包括约 120 FPS 的报告）来自仅注入鼠标事件的旧基准，未断言对象实际位移，不能用于证明真实拖动性能。基准现使用原生 Viewport.warp_mouse，并检查驱动对象确实移动及全部分组成员位移一致；真实结果见 [移动布局缓存验证](moving-layout-cache.md)。原有局部避让、远处静止和撤销行为回归仍有效。

复用方案评估：Godot 的 PhysicsDirectSpaceState2D.intersect_shape 已提供原生宽阶段空间查询，已有 RectangleShape2D/PhysicsShapeQueryParameters2D 足以查询拖动对象附近实体；优先复用，不引入自建网格、四叉树或第三方物理库。现有连线碰撞层为 0，标题通过既有 caption_rect 取得边界，对与局部实体相连的边更新实时几何，其余边不强制重算。编辑对象、碰撞、包含关系和事务历史继续使用既有节点与接口。

修复前反馈：1029 对象真实教程，开启自动物理时拖动约 1.61 FPS、p95 815 ms；松手约 1.31 FPS。相同操作仅关闭物理后，拖动约 222 FPS、p95 7.34 ms。因此卡顿主因是编辑事务期间的全图物理重排，不是可见内容的绘制数量。旧局部行为回归同时复现了远处相连节点/重叠节点移动，以及拖动分组时内部成员重新排布。

## 实际修复

指针开始拖动时，NodeRepulsion 保存选中根实体作为本次局部驱动者，通过原生矩形空间查询选择其附近的同层邻居。容器内部成员不参与整个容器的自动重排，容器和所有成员继续由既有世界坐标传播一起移动。该手势及其松手收尾不运行全图连通分量吸引；远处连线端点视为固定端，附近标题仍作为既有连线的碰撞表面。移出局部范围的被动节点停止漂移；每个邻居在一次手势中的让位范围限制为 influence_distance，默认 64 世界单位。没有修改实体的 freeze、保存位置、碰撞层或场景结构。

Alt 跨层移动在预览时暂停物理并保留手势范围，实际放置后按新位置重新建立局部范围。普通未指定局部驱动者的历史事务仍保留既有吸引语义；本次专门处理用户报告的节点/分组拖动。超出一个影响半径的严重初始重叠不再通过该手势自动全图重排。

## 检查

Linux X11 / Godot 4.8.dev6 / Compatibility / Iris Xe / 1280×800，1029 对象教程，关闭垂直同步、开启自动物理：修复后节点拖动约 195 FPS、p95 6.83 ms；最大分组（51 个后代）拖动约 154 FPS、p95 9.11 ms。两者使用实际输入路径、刚体积分、实时连线和分组预览，没有冻结测试对象。每阶段 1.2 秒，不能据此保证所有分组大小都稳定 120 FPS。松手历史快照仍有约 63 ms 峰值，另作独立优化。

加入原生历史比较后的最终发布版，119.96 Hz 显示器、开启垂直同步：节点拖动 120.10 FPS、p95 9.31 ms；51 后代的分组拖动 119.74 FPS、p95 9.63 ms。松手提交分别 23.42 ms 和 15.82 ms。导航测试冻结刚体、没有启动编辑事务，无法暴露这次问题；现在的回归保留真实刚体积分和自动物理，并检查远处位置不受影响。

local_drag_physics 验证邻居仍让位、远处相连/拥挤节点静止、每次被动位移不超过一个影响半径、分组成员相对关系不变，以及一次手势的一次撤销/重做。node_repulsion、linked_attraction、group_overview、edge_caption、navigation_cache、native_dirty 和 interaction_visual 回归通过。大图源文件哈希保持不变。独立格式化器未安装，使用 Godot 编译与 Git 空白检查。

通过 `mcp__godot_mcp__read_script`、`create_script`、`modify_script`、`execute_editor_script` 处理 Godot 文件与测试；没有读取场景文本或修改第三方插件。

## 用户手动验证（待执行）

1. 用新程序打开「教程操作.prg」，保留自动物理开启，放大后拖动一个节点。应明显跟手，只影响近处同层邻居，远处相连节点和其他原有重叠不自动移动。重点检查一拖就全图收缩、松手后远处持续漂移。
2. 拖动分组以及 Alt 跨层移动。分组成员应整体移动、相对布局保持原样，邻居只适度让位；重点检查成员重新排布、内部节点抖动或位置重复移动。
3. 松手后撤销/重做，再另存副本重开；拖动及邻居让位应属于同一步历史，连线、标题和分组保持连接。重点检查只撤销部分移动、标题碰撞丢失或未保存标记错误。

其他硬件、比当前测试分组更大的容器、高 DPI 真实鼠标拖动尚未人工验收。
