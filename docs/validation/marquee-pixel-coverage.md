# 框选矩形丢边

截图中的 L 形框来自屏幕像素覆盖不足。原 Line2D 已经 closed=true 且包含四角，但宽度是两个世界单位；例如缩放到 .125 时边宽只有 .25 屏幕像素，会因亚像素位置丢掉整条边。

复用 Godot Line2D、Transform2D 以及项目现有 line_antialiasing.res，不新增库。将世界四角转换到原生屏幕尺度的 Line2D，维持两像素实心边宽并加覆盖过渡；完整闭合、取消与框选判定仍使用原世界矩形。

使用 Godot MCP 读取与修改脚本、创建测试并执行独立测试进程。marquee_pixels_smoke 对 .02–3.0 的七档缩放和四个亚像素位置检查四边实际图像覆盖：原实现多次缺少 38 或 76 个采样点，修复后全通过；取消会隐藏并清空临时线。截图 /tmp/pg-marquee-regression.png 已目视检查。

用户手动验收尚未执行：重开新版应用，在教程操作的大图上缩小到 1%–25%，从空白处按左键拖出方框，应始终有四条连续边，松手正常选中，取消时无残留。失败时重点检查是否仍只剩 L 形、边框错离鼠标，或松手后选择与矩形不一致。
