# 局部避让与右键属性修复（Release 22）

## 改动与验证

右键只进行一次连线命中查询。查看属性和连线预览不启动历史事务；节点文字 / 尺寸与标题修改使用局部避让，纯颜色、线宽、箭头或方向修改跳过物理收尾，未改值直接应用不增加历史。

普通事务不再默认重排全图。节点创建与拖动明确指定局部范围；标题和连线创建的两个端点可以在位移上限内让位。全图算法只保留显式内部调用接口，未新增全图整理菜单。

复用现有局部求解器、Godot 原生空间查询、节点输入和历史快照，没有引入新依赖。Godot 文件通过 MCP 脚本读写与编辑器脚本执行处理；各独立修复已分别提交。

源脚本回归通过：真实右键 / 属性、局部属性 / 文字 / 标题、纯样式 / 空操作、物理范围、斥力、显式全图吸引、标题碰撞、局部拖动、真实分组包含、图片交互、多选、脏标记和渐进加载。大图与图片测试读取桌面原文件，源文件哈希不变。

1029 对象真实大图测试中，菜单约 38 ms，属性首次打开约 12 ms、后续约 5 ms；属性同步应用约 16 ms。编辑采样仍有约 59 ms 的单帧峰值，持续 120 FPS 尚未达到。渐进加载首次可见约 47 ms，文档构建约 2568 ms。详细测试与手动步骤见 [右键属性验证](context-properties.md)。

## 用户手动验证（待执行）

安装完成后，先保存并关闭旧窗口，再从系统菜单打开教程操作大图。右键几个节点选择属性，应及时显示正确对象。属性未变时点应用，应保持所有位置、不增加撤销步骤；只改颜色 / 线宽 / 方向，应保持所有位置；改文字 / 尺寸时只允许附近同层对象有限让位。撤销 / 重做各应恢复一次完整操作。
