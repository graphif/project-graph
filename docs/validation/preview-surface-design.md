# 分组预览的视觉优化

预览使用现有 Godot Panel/Label、StyleBox 和项目 Corners/Palette。Godot 原生样式已支持填色、边框、圆角和文字省略，项目缓存已支持屏幕尺度的资源复用；无需引入图布局库、文字布局库或新的依赖。本次只调整显示，不重排或修改保存的图数据。

设计：柔和的组内底色压低网格干扰，一像素的组边框和更大的连续圆角；顶部标题取消额外描边，增加留白与小色标；子节点使用明确的卡片底色与更轻的边框，保留自定义颜色；标题与卡片颜色分别根据所在表面计算可读对比度。连接仍使用原生 Line2D，降低默认连线的视觉重量。继续使用现有字号、样式和几何缓存。

使用 Godot MCP 脚本修改与编辑器脚本执行工具。preview_visual_cleanup_smoke 和 next_layer_preview_smoke 通过，覆盖明暗主题、顶部标题编辑、连接端点、颜色变化及快照不变；四个桌面实文件的四档缩放回归通过，已目视检查教程操作、快捷键教程和专用回归截图。代码与文档 diff --check 通过。

用户手动验收尚未执行：重新启动安装版，打开教程操作和快捷键教程并缩小。应看到柔和的分组区域、独立的顶部标题与清楚的下一层卡片及连接；放大恢复原节点。失败时检查浅色主题文字不清楚、自定义颜色丢失、标题或连接遮挡，以及节点保存位置是否变化。
