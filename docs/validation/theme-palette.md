## 用户手动验证

1. 在设置中的外观主题选项切换 Catppuccin Mocha / Catppuccin Latte，再打开菜单和属性窗口。应看到统一深浅配色及紫色强调；若出现旧绿色或局部错色，重点检查延迟窗口和控件覆盖色。
2. 新建两节点并连线，给其中一个节点设置自定义颜色，再切换主题、保存并重开。默认颜色应跟随主题，自定义颜色保持；重点检查旧默认色值是否被误当作自动颜色。
3. 选中两节点复制粘贴。应得到独立节点和连接副本端点的连线；若连线消失或连接旧节点，检查 ID 解码与引用映射。
4. 用 Tab 遍历设置表单，并在 150%/200% 缩放下检查焦点与文本。焦点应清楚、按钮可达；若缺控件或出现占位节点，优先检查上述引擎兼容性报错。
