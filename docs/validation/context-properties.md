# 右键属性卡顿验证

## 重复命中查询

在桌面 `教程操作.prg`（1029 对象）中，真实右键输入耗时约 5894 ms。临时计数确认一次点击调用 `Stage.edge_at` 393 次，共耗时 5846 ms；每条连线都在自己的 `_input` 中再次遍历全舞台连线。直接打开属性窗口只有约 15 ms，无法复现真实右键链路的卡顿。

将连线右键命中与菜单派发集中到 `LineEdgeCreator`，取消 `LineEdge` 的重复输入处理。复用 Godot 原生节点输入分发、舞台既有 `edge_at` 和菜单，不引入依赖；通用命中库无法替代包含预览、标题与曲线几何的项目规则，因此只修改现有集成逻辑。

`context_properties_smoke.gd` 使用真实鼠标位置与原生输入，覆盖三次右键节点 → 属性操作、窗口内容、逐帧时间、两个右键模式下的连线属性菜单和源文件哈希。关闭物理时回归通过，菜单约 54–226 ms，属性同步调用约 6–50 ms，帧最大时间约 8–20 ms（桌面其他程序运行导致负载波动）。菜单采用 300 ms 回归上限，用于捕获原来的秒级阻塞，不表示已达到 120 Hz。连线标题与交互外观回归通过。

仅此查询修复尚未解决启用物理时的卡顿：右键预览还会开启历史事务，导致没有局部驱动对象的全图物理计算。需要另一个独立修复。

## 右键事务隔离

连线历史事务已推迟到实际创建连线之前，预览、普通右键与取消预览不再主动提交历史。MCP 连接恢复后，启用物理的真实大图回归通过：三次菜单约 37–39 ms，属性首次打开约 12 ms、后续约 5 ms，采样帧最大约 5.4 ms。测试确认没有激活编辑事务、没有撤销项、全舞台快照不变。预览取消以及右键连线 / 左键连线模式下的创建、单步撤销和重做也通过。

## 编辑避让范围

纯颜色、连线线宽 / 箭头样式、连线反转使用不等待物理的历史提交；属性值未变化时直接返回，不建立事务。`History.commit(false)` 复用同一快照与撤销实现，只跳过不需要的物理收尾。

`visual_edit_physics_smoke.gd` 的五个场景（未改值直接应用、节点填充、颜色窗口、连线线宽、反转）在修复前都会激活避让并移动重叠节点。修复后全部通过，所有位置不变；实际样式修改仍能单步撤销 / 重做，空操作不增加历史。属性局部避让、真实右键和颜色窗口回归通过。

属性编辑、节点文字提交和连线标题提交已接入现有局部避让：节点作为驱动对象，标题以两个端点作为驱动对象。驱动对象固定，原生空间查询只纳入附近同层邻居，沿用已有单次被动位移上限。未引入新求解器或依赖。

新增 `property_local_physics_smoke.gd`。修复前，修改属性会移动远处两个重叠节点，重做还会恢复这些无关位移；修复后，属性、直接文字编辑和标题编辑均保持远处节点不变，单步撤销 / 重做通过。真实 1029 对象文件也通过；属性同步应用约 18 ms，属性更新采样 p95 约 43 ms、最大约 59 ms，标题采样 p95 约 7 ms。该采样不是持续 120 FPS 的证据。连线标题和局部拖动回归通过，源文件哈希不变。

求解器现在要求显式的范围请求，历史事务自身不再意味着允许重排。节点创建、文字 / 尺寸编辑和拖动使用局部范围。连线创建与标题编辑允许两个端点在同一局部位移上限内让位，避免把两个端点都固定而无法给标题腾出空间。没有范围请求的批量操作或删除保留其现有布局。

新增 `physics_scope_smoke.gd`，覆盖无范围事务静止、局部驱动固定、邻居位移不超过影响半径、标题端点有限让位、远处重叠节点静止，以及全图许可在事务结束后清除。修复前无范围事务会移动所有重叠节点；修复后全部通过。旧全图算法通过 `begin_global_layout()` 显式请求保留，仅提供内部调用接口，当前没有新增全图整理菜单。全图斥力、关联吸引与标题碰撞算法测试明确请求该模式；标题点击测试把曲线点放到画布中央并移动真实指针，避免根工具栏吞掉输入。

已实现的操作范围如下：

- 查看与选择只更新界面，不启动物理事务。
- 修改或拖动仅以改动对象为驱动，复用现有局部避让与 Godot 原生空间查询，约束同层邻居，并限制单次被动位移。属性修改应验证同样的局部范围，而不是退回全图计算。
- 全图重新布局必须显式请求，普通事务不会触发。分组成员作为整体跟随，整段操作只产生一个撤销步骤。新的全图整理界面尚未实现。

电脑已安装 Release 22，RPM 文件校验及正式入口打开教程操作文件通过。旧窗口需保存并重新启动才能使用新代码；用户手动操作尚待复核。

Godot 修改通过 MCP 脚本读写与编辑器脚本执行完成；脚本编译、相关测试和 Git 空白检查在提交前执行。

## 手动验证（待执行）

重新运行更新后的程序，打开教程操作大图，依次右键几个不同节点并选择属性。菜单应迅速出现，属性文字与点击节点一致；反复打开应保持响应。右键连线和连线标题应仍显示连线属性，右键拖到另一节点仍能连线。重点检查是否出现秒级冻结、选错对象、连线菜单失效或创建连线丢失历史。

不改变属性直接点应用，应不增加撤销步骤、不移动节点。只改颜色、线宽、箭头或方向时，所有位置应保持不变；修改文字或尺寸时仅附近同层对象可有限让位，远处节点应固定。检查撤销 / 重做是否一次恢复完整修改，以及附近或远处是否发生大幅跳动。
