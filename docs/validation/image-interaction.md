# 导入图片的点击与拖动

2026-10-02：图片场景仅连接 RigidBody2D.input_event，TextureRect 忽略鼠标；实际舞台 SubViewport 未开启物理拾取。真实输入测试复现了图片无法选中、拖动及生成撤销记录。

复用原生 TextureRect.gui_input，场景声明连接到图片脚本，再转入既有 Entity 选择、拖动及事务逻辑。与文本节点一样关闭重复物理拾取，保留碰撞层供连接/包含/避让查询。未另建拖动实现，没有新依赖；通用库无法替代引擎场景的输入连接。场景通过 Godot MCP 编辑器脚本中的 PackedScene/ResourceSaver API 修改，未读取或写入场景文本；脚本使用 MCP 读写工具。

image_interaction_smoke 通过原生鼠标输入验证选中、实际位移、单步撤销/重做及 Shift/Ctrl 选择。合成 PNG、桌面的教程操作.prg、教程节点.prg 均通过，源文件哈希不变。第三个快捷键教程没有图片，未用于图片交互验证。测试使用 Viewport.warp_mouse 设置真实指针位置，因为仅注入鼠标事件不能保证画布读取到对应的系统鼠标坐标。

待用户手动验证：重新启动更新版，打开教程操作或教程节点，直接按住图片拖动；应出现选中轮廓并跟随鼠标移动。Ctrl+Z/Ctrl+Shift+Z 应恢复位置，Shift+单击图片应加入多选，Ctrl+单击应只选图片。失败重点检查是否仍在旧运行窗口、是否点击了覆盖图片的分组预览、是否在连接/画笔模式。缩小到分组预览时，内部图片应保持隐藏且不抢输入；放大后恢复操作。实际桌面输入和不同缩放下的感觉仍需手动确认。
