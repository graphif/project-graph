## 命令面板打开延迟

源码确认：命令面板首次打开按需实例化；原打开路径先显示窗口再填充列表，且参与 0.18 秒滑动淡入、0.13 秒退出动画。这些是可感知等待的候选原因，没有实测证明唯一瓶颈。

本轮改为先准备命令列表再显示，并让命令面板直接打开/关闭，不进入弹窗动画状态机。其他弹窗动画保留。另外保留未变化的命令列表，避免每次清空后重新排版。在当前测试机四节点画布中，优化前重复打开到绘制完成约 539–736 ms；保留列表后重复打开约 5–16 ms。主题/缩放变化后的首次排版仍约 550–580 ms，尚未解决；不外推到大画布或其他机器。

手动验证：重启后点击右上角命令按钮，输入搜索，按 Esc，再连续打开几次。预期无淡入等待、无空白首帧，输入焦点立即可用，关闭不再短暂重新显示。若仅首次慢，重点记录窗口初始化和字体首次绘制；若每次都慢，比较空画布与大画布，并检查帧耗时，不能只测函数返回时间。

## 后续用户反馈对应修改（当前工作区已验证）

- 节点交互规则及兼容策略见 [节点编辑交互](../design/node-interactions.md)。主题父关系新增独立引用，Esc 手势取消复用 History 快照。
- 设置窗口通过 PackedScene API 重建：四个真实页面使用左侧导航；只保存显式创建的节点，避免内部 TabBar/滚动条/SpinBox 编辑框重复成为页面或幽灵控件。设置初始化后同步当前值，避免所有开关显示为默认关闭。
- 颜色窗口通过场景 API 改为常用色块、HEX 输入、预览、应用与默认颜色。移除 ColorPicker；HEX 非法时禁止应用，修改草稿不改变对象，按应用后进入一次历史。
- 包含关系连线从容器标题连接到后代；箭头方向依据实际末段，线身末端对齐箭头底边；预览使用同一端点几何。极短线不足以容纳箭头时只画线身。
- Alt 移动的起点、落点预览和目标框复用舞台圆角轮廓，保持 Line2D 节点反馈。
- 节点编辑启用自适应宽高及软换行，中文预编辑参与测量，编辑区有独立背景；候选窗的屏幕定位尚未验证；编辑时不再叠加旧尺寸的选择框。

补充手动步骤：打开设置，四个页面应只有常规/快捷键/外观/关于，切换页面和修改设置后重开仍正确；颜色窗口不再出现色轮，输入坏 HEX 不得应用，Esc 不改对象。把两个节点分别放在容器内外再连接/移动，箭头与线身应连续；按 Alt 拖动，预览三处框应圆角。自动检查覆盖范围见上表；真实按键、拖动和输入法仍按这些步骤验证。
