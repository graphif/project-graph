# 按补充要求保持预览圆角并减少框体重合

在 master 居中大标题、字号适配及半透明背景的移植上，应用用户明确补充的圆角与紧凑要求。复用项目 Corners 的原生 StyleBox 纹理缓存和 Godot Rect2；不使用物理避让、全图重排或新增布局库。只调整可见预览，保存位置和关系不变。

主分组保持真实范围，使用屏幕尺度的可见圆角；临近一层的真实子分组以原中心为基准显示最多 160×80 屏幕像素的紧凑预览，避免继续用包围全部后代的大框相互叠压。可见的细长分组至少提供 24 像素的短边，避免圆角被挤成直角；不可读的小框不绘制。端点跟随实际预览矩形。圆角使用现有纹理缓存，尺寸变化沿用已有缩放分档。

通过 Godot MCP 修改脚本、创建回归并执行原生测试。rounded_compact_preview_smoke 在此前版本上复现圆角消失和框体重合，调整后通过，覆盖预览原中心、重合面积显著下降、连接端点和快照不变；master_preview_visual、group_overview、next_layer_preview、四实文件四档缩放及渐进加载通过，已检查专用回归和实文件截图。1029 对象基准平均约 160/127/145 FPS，仍有帧尖峰，不宣称严格稳定 120 Hz。安装与用户手动验收尚待完成。用户手动验收：重开安装版，打开含嵌套分组的图并缩小。预览框应始终有清楚的圆角，子分组块比原范围紧凑，连接指向新边界；放大恢复原框。失败时检查圆角变成直角或裂缝、子框仍包住所有后代、端点漂浮，或节点保存位置发生变化。
