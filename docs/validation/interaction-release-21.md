# 交互修复安装验证（Release 21）

## 实际改动

- 修复原生物理位移未通知舞台布局的问题；拖动分组时，所有后代成员跟随，同一次手势保持一次撤销/重做。
- 图片 TextureRect 的 GUI 输入进入 Entity 的选择、拖动和历史逻辑，禁用重复物理拾取。
- Shift 单击追加选择，Ctrl / Cmd 单击独占选择；同时按下时 Ctrl / Cmd 优先。普通单击保留已有多选的拖动行为。
- 缓存包含拓扑和容器布局，延后隐藏连线的显示更新，减少大图拖动中的重复工作。

Godot 文件使用 MCP 的脚本读写、编辑器 GDScript 执行及原生 PackedScene / ResourceSaver 类别处理。复用 Godot 的输入、节点、物理和资源接口，没有新增第三方依赖。各项修复与基准校正分别提交；安装包版本单独提交。

## 用户手动验证（尚待执行）

先保存并关闭已运行的旧版本窗口，然后从系统菜单或 `/usr/bin/project-graph` 重新打开项目。Godot 中已经运行的游戏实例也需要重新启动。

1. 打开 `教程操作.prg`，拖动“视野操作方法”分组。其 12 个成员应一起移动，位置仍被分组包含；撤销 / 重做各恢复一次完整移动。重点检查是否只移动外框、成员漂移或一次手势需要多次撤销。
2. 在教程操作或教程节点中单击一张图片并拖动。应能选中、移动；撤销 / 重做恢复图片位置。重点检查图片是否吞掉点击、拖动不响应或历史缺失。
3. 单击节点 A，Shift 单击 B，两个节点应同时选中；再 Ctrl 单击 A，应只选中 A。对图片和缩小后的分组标题重复操作。重点检查修饰键是否被解释为切换取消或仍保留其他选中对象。
4. 缩小到分组预览出现后拖动含成员的分组，再放大。成员与可见连线应在新位置显示。重点检查预览是否滞后、连线端点是否保留旧位置以及邻近对象是否大范围跳动。

持续 120 FPS、不同显卡 / 物理设置的性能与正常关闭时资源清理仍需进一步验证和优化。
