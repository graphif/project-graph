# 已连线文本块的轻微引力

## 实现前的复用选择

评估 Godot 原生 DampedSpringJoint2D、RigidBody2D 和当前 NodeRepulsion 求解器。原生弹簧适合持续的两体连接，但这里需要整个连通集合及连线命名块参与、编辑事务限定、包含层级、抓取/输入中的固定对象；另建关节会增加第二套生命周期与暂停逻辑。因此复用现有 NodeRepulsion、RigidBody2D 速度、Vector2.move_toward / limit_length、Dictionary 和 History，只补连通集合的低强度目标速度计算。使用邻接字典和队列遍历连接，避免所有节点两两施力；命名块复用已有的端点权重分配。不引入依赖，不新增持久化对象或独立力学引擎。

## 预期行为

- 同一连通集合的 TextNode 与 LineEdge 命名块共同参与轻微凝聚，包括间接连接的节点；无连线对象保持原有排斥行为。命名块的作用通过已有权重传给端点，不成为独立漂移的对象。
- 距离较远时缓慢靠近，近距离保留节点和命名块的安全间隔；同一对端点的重复/反向连线不叠加引力。
- 编辑事务及收尾期间生效，关闭物理、隐藏舞台或结束事务后停止；载入、撤销和空闲画布不自动重排。
- 拖动、冻结、编辑或投掷中的对象不被引力接管。跨分组连线作用于双方对应的同层容器，保留成员相对位置；祖先与自身后代之间不施加拉力。
- 连线引力先于现有防重叠约束执行，让安全间距优先。
- 默认引力加速度上限 180 世界单位/秒²，目标速度上限 80 世界单位/秒；距离中心较近时逐渐减弱。文字/命名块尺寸与 160 世界单位的静止范围共同限制目标速度。等待历史稳定时也检查尚未完成的轻微引力，避免高物理更新率下因初始速度较低提前提交。

## 自动验证

`linked_attraction_smoke.gd` 在无头及 X11 图形模式通过：连通链、间接连接、未连接对象不动、命名块参与、重复/反向连接、冻结/抓取、关闭物理、隐藏舞台、跨组整体运动、240 次/秒物理更新下的收尾、稳定后停止以及撤销/重做。`node_repulsion_smoke.gd` 与 `edge_caption_magnet_smoke.gd` 通过，保留近距离避让。一次 Wayland 测试完成全部断言并输出 PASS 后，在退出阶段达到外部超时；因此完整进程成功结果以无头与 X11 的退出码 0 为准，不将该次超时计作通过。

Godot 文件通过 MCP 脚本读取、修改、创建和编辑器脚本执行工具处理；没有增加或文本编辑场景文件。真实输入、触控板与大型用户文档验收仍待执行。

## 用户手动验收（待执行）

1. 开启物理，创建两个相距较远的文本块并连线，或拖动已连接的一个文本块：另一端应轻微靠近。无连线的远处文本块不应随动。重点检查突然跳动、速度过快或拖动者被拉离鼠标。
2. 给连线较长命名，再添加反向连线：应继续保持文字块与命名块间距，不因多条线加倍拉近。重点检查重叠、持续振荡。
3. 关闭物理后拖动，确认没有引力；重新开启后再操作连线对象，应恢复轻微拉近。
4. 保存并重开、撤销/重做刚才的拖动：布局应保持或准确恢复，不在空闲期间继续收缩。
5. 连接两个不同分组中的成员再拖动：应整体带动相关分组，内部相对布局保持；祖先分组连接自身成员不应造成收缩循环。
