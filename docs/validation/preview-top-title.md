# 预览视觉整理：参考 master 顶部标题

参考 master 991be19283139fb58a3fd7e33a3f5242e92190c7 的 SectionRenderer.renderTopTitle，以及 EntityRenderer 的大标题模式分派。master 同时提供覆盖标题和框外顶部标题；本次采用后者，使标题不挤进组内节点。没有移植 canvas 底层绘制调用，仍使用 Godot Panel/Label、Line2D/Polygon2D。

实际调整：

- 组标题移到框外上方，使用单独背景标签。部分框移出视口时，标题留在视口内；双击标签仍调用原节点编辑器。
- 下一层虚拟分支使用分支根节点自身的矩形，不再画包住全部后代的大矩形。真实嵌套分组仍保留真实框。
- 子标题保持约 14 屏幕像素，单行超宽用原生 TextServer.OVERRUN_TRIM_ELLIPSIS，避免缩成碎字；尺寸不足的块暂时不显示，继续放大恢复。
- 子块边框减为一屏幕像素。深层内容继续隐藏，下一层连接保留；根连接从实际可见标题出发。
- 标题背景跟随主题，不修改保存位置、层次、物理或历史数据。

复用评估：Godot Label 自带省略、裁切和对齐；Transform2D/Rect2 处理现有世界坐标和视口，项目 Corners 与字体缓存提供样式。无需新增文字排版库、图布局库或第三方依赖，也不启动全图避让。

通过 Godot MCP 的原生文件读取、脚本修改/创建和编辑器脚本执行完成。preview_visual_cleanup_smoke 修复前顶部位置、后代大矩形和省略行为三项失败，修复后通过；另覆盖可读字号、根连接端点、视口标题、双击编辑、主题和快照不变。group_overview、next_layer_preview、canvas_antialiasing、progressive_loading 通过。四个桌面实文件重新加载及四档缩放通过，已检查教程操作、快捷键教程和专用回归截图。一次实文件批量测试在切换文件时超过 30 秒；加加载边界输出后重跑约 12 秒全部通过，不能据此宣称加载时间固定。

1029 对象同机缩放测量：局部约 208 FPS、宽范围冷/热约 148/171 FPS；p95 约 11.6/12.6/10.4 ms，单帧最大约 38/36/30 ms。结果随桌面负载变化，严格稳定 120 Hz 仍未达到。

用户手动验收尚未执行：重开安装版，打开教程操作.prg 并缩小到原来截图的范围。标题应在框外，小标题不与大标题叠在一起，子分支不再出现包裹后代的重叠大框；连线仍可见。放大恢复完整文字，双击顶部标签可编辑。失败时检查标题被菜单边缘裁掉、长文字缩成碎字、连接从空白处出现、或正常保存位置发生变化。
