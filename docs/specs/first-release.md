# 首版实施规格：有出处的观点图

状态：首版开发基线，功能未完成；来源为 [软件设计调研](../research/software-design.md) 第 6、7、13、14 节。现有能力以 [现状表](../development/current-state.md) 为准。

## 问题与目标

面向围绕复杂问题阅读材料的独立研究者和开发者。用户需要从零散摘录形成观点、解释关系并找回依据，减少画布、笔记和报告间的重复维护。目标用户与收益仍是待验证假设。

首版完整任务：围绕一个问题手动整理约 10–15 份材料，形成包含观点、关系文字与来源的画布；搜索证据；保存重开；导出一份可读的 Markdown 说明。材料规模是验收任务，不是性能承诺。

## 必须交付的行为

| 编号 | 用户需要 | 可观察的完成条件 |
| --- | --- | --- |
| R1 | 可靠保存自己的材料 | 支持格式往返保留 ID、文本、关系、包含及新增字段；写入失败不误报成功、不破坏上次有效文件 |
| R2 | 知道哪些输入不能安全处理 | 未知类型、字段、重复 ID、损坏引用及不支持版本在替换当前文档前被报告；不能静默丢弃再覆盖原件 |
| R3 | 快速记下内容，再补详情 | 保留现有文本输入；详情为独立纯文本，允许为空；确认一次产生一次历史记录，取消不改变内容 |
| R4 | 说明两个内容之间的关系 | 连线文字可为空、可编辑、可搜索；移动端点保持归属；保存、复制、撤销保留文字 |
| R5 | 区分原文和自己的解释 | 节点与关系可关联来源标题、URL/路径、定位说明及原文摘录；修改详情不改写原文摘录 |
| R6 | 找回证据 | 当前画布搜索覆盖文本、详情、边文字、来源标题与摘录，支持中文两字词；结果显示字段并定位对象，允许返回原视野 |
| R7 | 输出可阅读的说明 | 全画布或选区导出 Markdown，包含节点文本、详情、关系两端与文字、来源和摘录；容器选区包含后代和内部关系 |
| R8 | 放心尝试与恢复 | 新增字段适用既有复制、删除、取消、撤销和重做；完整用户操作不拆成不可预测的多步历史 |

## 交互与异常约定

详情、关系文字和来源从所选对象的明确属性入口进入，支持确认和取消。中文组合输入期间，Enter/Esc 优先交给输入法。空内容合法，不要求先分类。

来源由用户手动录入；首版不抓取网页、不解析 PDF。URL/路径仅在用户明确打开时访问。来源不可达时仍能读到保存的摘录，并显示无法打开；不自动跳到相似内容。定位说明可以填写页码或章节，不承诺精确 PDF 高亮。

关系证据属于关系自身。首版保留现有连线数量规则，自由文字表达含义；关系类型系统、平行语义关系及主题结构迁移后续单独设计。新增文字不能悄然改变 Tab/Enter 的现有行为。

复制产生独立副本，新字段一并复制，内部引用按 ID 映射恢复。当前没有共享对象库，不引入“删除呈现但保留全局对象”的半成品语义。现有 Alt 中心锚点保持不变。

Markdown 输出是快照，保留来源和对象 ID 以供人工对照；不是可回写项目文件。外部关系不自动拉入选区之外的对象，输出明确的范围说明与被排除外部连接数量。导出顺序由预览中用户确认的节点列表确定，不以任意语义边推导树；取消不写文件。

## 数据与兼容要求

新增持久字段先定义默认值、旧文件读取规则及版本策略，再实现 UI。普通受支持的旧文件无需手工补字段。含未知数据的文件首版优先拒绝有损打开并保留当前文档和原文件，完整迁移另立任务。

保存的成功边界是完成可恢复写入流程；失败保持脏状态。备份与撤销不能互相替代。旧 master 格式至少明确识别或报告不支持，首版不承诺完整转换所有旧对象与附件。

## 不在首版范围

跨画布共享、独立对象库、完整富文本、自动来源提取、PDF 阅读器、折叠与自动布局、强类型关系系统、AI、网络同步、协作、插件平台及全面重写存储。既有相关功能可保留，但本轮不扩展。

## 完成门槛

R1–R8 对应 [验收方案](../validation/first-release.md) 的 A1–A9；所有数据丢失与事务完整性问题解决，剩余限制明确记录后，才能称首版完成。能画图、字段存在或单个冒烟脚本通过都不足以替代完整任务验收。
