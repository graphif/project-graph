# PRD：从画布编辑到有出处的观点图

版本：0.3，2026-09-29。状态：产品设计提案与下一阶段开发基线；未实现项不代表现有能力。本文接替旧首版规格维护需求，任务只在 [TODO](../development/TODO.md) 勾选。依据是 [软件设计调研](../research/software-design.md)、本次 Godot MCP 只读源码复核和已有主题专项记录；没有用户行为统计，不将低优先级写成“没人用”。

## 1. 产品判断

目前的主要缺口不是画布操作数量，而是内容从输入到解释、核查、输出的连续流程。保留快速输入、自由摆放、分组、连线与撤销；先让文件可靠，再让每条观点能说明依据。菜单中没有实际行为的命令应隐藏或明确禁用，不应让用户点击后才发现只是占位。

首要用户假设：独立开发者、研究者，以及围绕复杂问题阅读材料的人。核心任务是用约 10–15 份材料形成一张有依据的观点图，几天后能找回原文，并输出可读说明。这个规模是验收样例，不是性能上限或容量承诺。一次性海报、团队项目管理、自动生成知识库不是本阶段的主任务。

用户应能回答三个问题：我在讨论什么；这些内容为什么有关；依据在哪里。增加功能的门槛是帮助其中一项，或保障保存和恢复。用户明确要求的基础绘图能力 R12–R18 同属必须交付范围，不能以知识工作台定位为由删减。

| 功能 | 现状证据 | 决定及理由 |

| 文本/Markdown 批量生成 | generate 按行与缩进创建对象 | 保留为快速录入，明确支持子集；不承诺完整 Markdown 解析 |

| 插件市场、扩展窗口 | _run 只提示运行时尚未移植 | 从默认产品入口收起；配色文档和内置主题保留，插件加载器延后 |
| 透明窗口、狙击镜、笛卡尔网格等命令 | 存在于 SUPPORTED，但已读 _run 无相应分支，亦不属于文件/帮助分发 | 先修“可用但无动作”的状态；没有闭环实现前不展示为可用功能 |
| 自动命名模板、逻辑节点、开发测试菜单 | 菜单目录有定义，但不在已读支持列表，菜单构建会过滤不可用项 | 保持未实现入口隐藏，核对帮助与命令面板；不凭目录存在安排整套补齐 |
| 随机聚焦、回到原点、释放按键 | 有运行分支；后两种停止操作存在用途重叠 | 随机聚焦移到实验/调试；停止当前操作保留为可靠退出路径，减少同义入口 |
| 物理拖动、画笔 | 属于现有空间操作基础 | 保留为可选；不继续扩展特效。停止漂移、关闭物理后稳定阅读优先 |
| 专注与隐私遮罩 | 设置会影响工具栏/状态栏与 PrivacyCover | 保留现有范围；遮罩不宣称加密或数据访问保护 |
| 多种导出、打印 | 有 SVG、PNG、文本、Mermaid 与浏览器打印入口 | 保留兼容路径，主入口收敛为一次“导出”，首版重点补带证据的 Markdown |
| Mocha/Latte 与更多换肤 | 内置主题已专项检查，设置窗口仍有兼容性报错 | 完成可读性和设置兼容修复，并交付其他配色及用户自定义主题颜色（R16）；不新增无关图标库 |

已有菜单构建会过滤 _available=false 的条目，因此“目录中有定义”不等于运行时可见；主要问题是错误地列为可用的命令，以及未实现功能的占位提示。源码证据入口：[main](../../src/main/main.gd)、[菜单目录](../../src/main/menu_catalog.gd)、[文件操作](../../src/main/file_actions.gd)、[画布操作](../../src/main/workspace_actions.gd)、[项目文件](../../src/project_file.gd)、[恢复注册表](../../src/stage_object_registry.gd)。本轮未直接读取场景文本，也未运行上述功能。

## 3. 首版使用流程

1. 新建画布，用首个文本节点写下问题；无需先建分类或填写表单。
2. 粘贴材料，快速创建节点；正文保持短，较长解释放在独立详情中。
3. 自由摆放、分组、连接观点；连线允许留空，也可填写“支持”“与……冲突”等自由文字。
4. 给节点或关系添加一条或多条来源，分别保存地址、定位说明和原文摘录。
5. 搜索关键词，看到命中对象及字段；定位后可返回此前视野。
6. 确认保存，关闭重开；选择全部或一个分组，调整输出顺序并导出 Markdown。

属性编辑复用已有入口，内容、来源、外观分区；不增加另一份可独立修改的正文。编辑采用草稿，应用一次对应一次撤销。切换选中对象或关闭有未应用编辑的窗口时，明确提供应用、放弃、继续编辑，不能静默覆盖草稿。

| R2 / P0 | 打开前知道是否会丢数据 | 未知类型/字段、坏引用、重复 ID、容器循环、非法数据及不支持版本在替换舞台前报告；失败保持当前文档和原件 |

| R4 / P1 | 说明关系含义 | 自由文字可空；画布标签与正确连线绑定，移动端点仍可读；保存、复制、删除恢复均保留文字 |

| R11 / P1 | 读懂当前节点的关系 | 关联列表显示方向、两端、关系文字及来源条数，定位连线或端点；不重复实现全局图谱分析器 |

### 4.0 用户指定的基础能力（全部必须交付）

用户提供的比较表没有产品列名，其中 ✅、❌、💰 是比较标记，不能当作本项目实现证据，也不转化为付费限制。以下每一行均为交付要求；既有能力先复核并补齐，缺失能力实现后验收。分批开发只表示依赖顺序，不表示可选或无限期暂缓。

| 编号 / 优先级 | 用户需求与边界 | 完成条件 |
| --- | --- | --- |
| R12 / P1 | 树形图（思维导图） | 创建根、子主题和同级主题，编辑、移动、连接与删除；Tab/Enter 行为明确，树关系可保存、复制、撤销；多父与环不被误当成唯一父主题 |
| R13 / P1 | 流程图（拓扑图） | 自由创建节点和有向连线，表达分支、汇合及环；支持移动、修改方向和删除，不强制树结构；流程顺序不靠屏幕位置推断 |
| R14 / P1 | 文本节点与 LaTeX 数学公式节点 | 文本节点保留中文编辑；公式节点可创建、编辑 LaTeX 源码并显示排版结果，至少支持分式、上下标、根式、矩阵和常见数学符号；错误源码可修正且保留，不能用普通文本冒充公式渲染 |
| R15 / P1 | 直线、曲线、折线 | 三种样式可选择与切换，移动端点后路径、箭头、标签与碰撞命中一致；缩放、复制、保存重开、撤销及图片/SVG 导出保留样式；不以曲线模拟折线或静默降级 |
| R16 / P1 | 深色主题、其他颜色主题、用户自定义主题颜色 | 保留深浅主题，提供额外可选择配色，并允许编辑语义颜色、预览、应用、取消和恢复默认；设置重启保留，界面与画布一致，用户显式对象颜色不被覆盖；不能只提供节点改色来代替主题自定义 |
| R17 / P1 | 自动计算 | 首个交付切片采用画布计算节点：输入数值/表达式，以稳定对象引用组成依赖，上游变化自动更新结果；支持四则运算、括号和明确的数值规则；错误、除零、缺失引用、循环依赖明确显示并可恢复，不沿用过期结果冒充成功；不执行任意脚本 |
| R18 / P1 | 由按键序列组成的快捷键 | 支持依次按键触发命令（如先 G 再 H，与同时按键不同），提供绑定编辑、当前序列提示、超时和 Esc 取消；处理前缀/重复冲突，文本输入与中文 IME 不被抢键；重启保留并与命令可用状态一致 |

### 4.1 数据与兼容

节点增加独立详情、证据记录集合；关系增加文字、证据记录集合。集合中每条记录有稳定局部标识、标题、地址、定位说明和摘录；允许不完整录入，不做全局去重或共享来源库。旧受支持文件缺少新增字段时取空值，新版本策略必须在开发前确定。未知字段不能以“有默认值”为由静默丢弃。

复制证据为独立记录；节点与连线 ID 按现有规则重新分配。来源记录的局部标识不充当跨画布共享身份。历史覆盖新增、编辑、删除来源记录。图结构继续采用当前数量限制，不新增平行关系、强类型边或跨画布对象库；边文字不能改变 Tab/Enter 对父主题的判定。

### 4.2 搜索、范围与导航

“快速打开”按文件名/路径找 .prg；“搜索内容”默认当前画布。保留大小写选项，空查询显示使用提示；同一对象多个字段命中合并展示字段标记。定位使用稳定对象 ID；对象已删除则更新结果并说明，不跳到无关对象。首版提供本次搜索前视野的一步返回，不做全局浏览历史。

导出容器包含后代与内部连线，选中的关系同时纳入其两端说明；不沿任意连线无限扩张范围。外部关系统计并提示，不自动拉入整张图。复制的容器/内部边范围复用既有规则，并单独说明“只选边时不复制外部节点”，避免与导出说明混淆。

Markdown 的阅读顺序来自用户确认的节点清单，默认按稳定顺序列出；不能把所有语义边推成父子树。环、多父关系使用独立关系表，避免无限递归和信息遗漏。导出内容是预览时的快照，预览后编辑画布需明确刷新，不悄然输出不同内容；导出不是可回写项目格式。纯画笔在 Markdown 中提示未包含并建议图片导出，不能静默丢失。

### 4.3 异常、反馈与恢复

来源地址不存在或打开失败时保留摘录并报告原因；URL 与文件路径由用户明确打开，不自动抓取内容。先限制可打开的地址类型为网页和本地文件，不把任意字符串当命令执行。

保存、另存为、全部保存、关闭前保存共用成功/失败语义。备份恢复打开为副本，后续覆盖旧文件必须由用户显式选择。首版只补手动备份的可发现恢复流程，不承诺定时备份、崩溃恢复或掉电安全。

## 5. 界面组织

- 常用命令保留新建、打开、保存、撤销/重做、搜索、导出和设置；不重做全部菜单布局。
- 当前选择的属性优先展示内容与来源；外观次级展开。空选区给操作提示，多选说明可批量修改的字段，不错误显示某一个对象的正文。
- “更新引用”调整为自动刷新关联视图，手动刷新只作为恢复入口；展示的是图关联，不叫证据库。
- 随机聚焦、开发测试放入调试范围；未实现的插件、逻辑节点、透明窗口等入口先收起。是否永久删除由实际使用反馈决定。
- 延续 [UI 规范](../design/ui-style.md)、[Mocha/Latte 配色](../design/color-system.md) 和 [图标规范](../design/icons.md)。新增界面必须覆盖键盘焦点、主题、缩放、中文输入和错误状态。

## 6. 明确不做与重启条件

| 暂缓项 | 原因 | 何时重新评估 |
| --- | --- | --- |
| 新图标库、透明度特效 | 不解决证据与输出缺口 | 核心流程完成且可读性确有需求 |
| 完整 Mermaid/Markdown 双向导入 | 语法与无损转换成本大 | 实际材料以该格式为主，现有文本导入持续造成重复劳动 |
| 自动保存/崩溃恢复 | 需明确版本、冲突及恢复策略 | R1/R2/R10 完成后单列规格 |
| 折叠、锁定、局部布局、只读浏览 | 有潜在阅读价值，但增加状态与事务复杂度 | 重访任务明确出现定位/误拖负担时做下一切片 |
| 全局来源库、多画布引用 | 需要内容与呈现身份迁移 | 用户反复维护相同内容副本，且能理解共享修改语义 |
| AI、同步、协作、插件市场 | 不能替代基本文件和内容契约 | 首版持续使用后出现明确需求，再评估成熟库与网络边界 |
| 重写数据库、全文引擎或技术栈 | 当前证据不足 | 真实样本性能/可访问性测量证明现有路径不满足要求 |

## 7. 复用与实现约束

优先复用 StageObjectRegistry、History、ProjectFile、现有属性/搜索/关联窗口与命令目录；复用 Godot 原生字符串匹配、JSON/ZIP、文件接口和节点控件。本轮需求修订不引入库，不写自制通用解析器或新权威存储。R12–R18 实施前先评估 Godot 节点、Curve2D、Theme、输入事件、Expression 等原生能力，以及成熟的公式排版、表达式和快捷键库；这只是候选方向，尚未完成选型。原生能力不满足时记录社区候选、不采用理由及集成成本；选用依赖必须固定版本和哈希，核实许可证、Godot 版本、导出平台和离线运行兼容性。禁止以占位渲染或自写通用 LaTeX 解析器交差。SQLite/FTS、布局库、同步库继续按 [设计决定 D6](../design/decisions.md) 延后；实施时若出现原生能力缺口，再核实候选版本、哈希、许可证与平台兼容。

验收尽量从“用户命令 → 保存/重开或撤销结果”这一条边界验证，不以私有方法存在为通过依据。所有可见反馈由节点表达。Godot 文件仅用规定 MCP 工具处理；新增测试与运行仍须针对对应任务另获授权，主题测试授权不扩展为本 PRD 的功能测试授权。

## 8. 发布与效果验证

R1–R8 沿用 [A1–A9](../validation/first-release.md)，新增 B1–B3 对应 R9–R11，C1–C7 对应 R12–R18，见同一验收文档。主题专项通过不替代 U1–U6；设置窗口内部控件兼容性问题是发布前必须处理的已知问题。

发布门槛：全部必需需求有实现和运行证据；保存失败不损坏上次文件；坏输入不替换当前图；新字段往返与撤销无丢失；菜单无无动作可用项；完整任务可以完成。导出构建、目标系统及键盘/缩放/IME 验收均需记录，不能以开发机冒烟通过代替。

产品收益验证采用真实材料：记录形成观点图的完成情况、寻找指定摘录的耗时、重访时能否解释关系、导出后需手工补写多少内容以及发生的数据修复。先形成基线，不编造“效率提高百分比”或使用率。若关系文字与来源录入打断输入且没有帮助核查，先简化入口；若用户只需要一次性图表，缩减知识管理路线。不得为研究观察默认添加联网遥测。
