## 文档维护规则

规格维护目标行为；现状表维护带证据的实现状态；TODO 维护工作顺序和任务勾选；验收文档维护操作与结果。不要在多份文件重复维护完成勾选。

开始开发前补齐相关入口的源码复核；完成改动后更新现状证据和验收记录。源码存在不等于运行通过。每个独立功能或修复一个原子提交；测试、构建及 Godot 运行继续按 [AGENTS.md](../AGENTS.md) 获得授权后执行。

首版范围变动时同时更新规格、任务依赖和验收编号。研究材料说明推导依据，不自动扩大首版范围。
