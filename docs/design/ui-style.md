# UI 风格与一致性规范

状态：2026-09-29 建立的首版规范。现有值来自 Godot MCP 脚本读取，后续已运行内置主题验证；目标规则不代表已全部实现。本文是 UI 组件与交互风格的维护入口；配色由独立的 [配色与主题预设规范](color-system.md) 维护，功能范围见 [首版规格](../specs/first-release.md)。

## 1. 风格与适用范围

沿用现有桌面编辑器方向：紧凑、清晰、低干扰，以画布内容为主体；深色采用 Catppuccin Mocha，浅色采用 Catppuccin Latte，统一使用 Mauve 紫色强调；取消原明亮绿色主题方向。菜单、工具栏、侧栏、详情、设置、属性窗口、确认框与空状态遵循同一套角色和组件规则。

画布内容与应用界面分别管理：用户自定义节点颜色、字号及线型不能被主题切换覆盖。画布缩放只改变画布；UI 缩放控制界面。系统原生文件选择器允许遵循平台风格，不能把它作为自定义弹窗的像素对齐基准。

## 2. 配色角色

颜色原值、语义角色和主题插件预设契约统一见 [配色与主题预设规范](color-system.md)，本文不重复维护色值。内置 Mocha/Latte 已完成运行时接入，验证边界见 [主题验证记录](../validation/theme-palette.md)。

错误、警告、成功同时配文字或图标。深浅主题均需人工检查文字、焦点与禁用状态可辨认；尚未测量对比度，不宣称符合某项无障碍标准。

## 3. 字体、尺寸与间距

| 项目 | 基线或目标 | 状态 |
| --- | --- | --- |
| 普通界面文字 | 14 逻辑像素 | main 默认值，源码确认 |
| 弹出菜单文字 | 15 | main 菜单配置，源码确认 |
| 窗口标题 | 16 | DialogTheme，源码确认 |
| 菜单图标 | 18 × 18 | main，源码确认 |
| 对话框按钮最小尺寸 | 88 × 36 | AcceptDialog 配置，源码确认；自定义窗口仍待核对 |
| 窗口 / 菜单圆角 | 12 | 相关配置，源码确认；部分 AcceptDialog 面板为 10，作为组件差异核对 |
| 普通输入框 / 次按钮圆角 | 5 | DialogTheme，源码确认 |
| 主按钮 / 菜单项圆角 | 8 | 已读配置，源码确认 |
| 新面板布局间距 | 4、8、12、16、24 的逻辑尺度；字段间 8、分区间 16、面板内边距 16 | 新界面目标，尚未全局落地；现有菜单和窗口专属边距不机械替换 |

字体复用项目已有字体与回退配置，不为每个窗口引入新字体。具体字体家族和中文字形覆盖需 UI0 经 MCP 复核资源后补证据。采用逻辑尺寸，交由统一缩放处理；文字增长、中文换行与长路径不能遮挡按钮。字段标题与输入框按列对齐，不用空格凑布局。

## 4. 组件与状态契约

| 组件 | 一致规则 |
| --- | --- |
| 按钮 | 一个提交区域只保留一个主要操作；文字用“保存”“导出”等具体动词；次操作复用普通按钮；危险操作必须说明对象和范围 |
| 输入框 / 详情编辑 | 标签始终可见，提示文字不能代替标签；只读与禁用可区分；非法值保留输入并就近说明；确认、取消行为依规格 |
| 列表 / 搜索结果 | 悬停、选中、键盘焦点分别可辨认；命中字段与上下文明确；空结果给出当前查询与下一步操作 |
| 标签页 / 开关 | 活动页与键盘焦点可见；开关只表达二元持续状态，不伪装成执行命令的按钮 |
| 弹窗 | 标题说明任务，内容、操作区与间距一致；焦点进入合理控件，关闭后返回触发入口；不可见窗口不得继续接收输入 |
| 菜单 / 图标按钮 | 相同命令保持相同名称、图标及快捷键提示；禁用原因可理解；图标按钮有文字提示；不以图标形状差异暗示不同操作 |
| 状态反馈 | 等待、成功、失败、不可用和空状态有明确区分；保存失败不能显示成功或清除脏状态；错误文本给出可执行的下一步 |

优先复用 Godot Theme、类型变体及已有 DialogTheme、LocalTheme。复用 DialogButton、DialogPrimaryButton、DialogField、DialogOption、SettingsSwitch、DialogTabs 等已有变体；新 TextEdit/证据列表需要补统一变体，不能每个窗口另写完整样式。临时反馈仍由节点表达。

弹窗多行输入统一使用 DialogTextEdit，复用 surface.field、text.primary、text.secondary、surface.selected 与公共焦点样式；颜色选择按钮复用 DialogButton。透明内容面板必须配合 Window.transparent_bg，由窗口边框样式提供主题背景，避免不透明视口遮住背景形成黑块。本次公共样式修正仅完成源码修改，深浅主题、缩放和交互画面尚未验证。复用 Godot 内置 Theme、Window 和现有 DialogTheme 即可，无需新增第三方 UI 依赖。

图标选型与映射以 [图标规范](icons.md) 为准，优先复用现有菜单 Lucide 映射与资源；窗口控制图标保留平台角色。其他图标目录的存在不证明它们都正在使用；UI0 核对实际引用后决定保留范围。当前不新增图标库、字体依赖或第三方 UI 框架。

## 5. 输入、主题与动效

圆角控件统一复用现有 SVG / StyleBoxTexture 路径处理抗锯齿，避免透明弹窗内小控件使用不同的边缘混合路径。小控件保留组件声明的圆角半径（上限 12），不再统一放大到 12，以减少九宫格对短控件的挤压。本次为针对细碎暗边的源码修正，尚待在深浅主题及 100%、150%、200% UI 缩放下人工复核边缘、焦点与圆角形状。

键盘焦点必须可见，Tab 顺序遵循阅读顺序；输入法组合输入优先于画布快捷键。Enter/Esc 不得在一次事件里同时确认文字和触发画布操作。焦点提示不能依赖鼠标悬停。

主题切换覆盖已打开窗口、之后才打开的窗口、菜单、侧栏和画布默认配色；跟随系统模式与手动模式的显示文案一致。切换主题不移动内容、不改变持久数据、不重置当前编辑。

现有弹窗打开/关闭默认 0.18/0.13 秒，主题过渡默认 0.4 秒，仅为源码基线。目标是动画可中断、连续操作以最后选择为准、关闭后无残留遮罩。关闭动效应覆盖弹窗与主题过渡；现有 effects 设置是否覆盖这些路径尚未确认。物理开关与界面动效开关职责不同。

## 6. 文案与文档一致性

用户界面用“节点、连线、详情、来源、摘录、画布”；Item、Occurrence、MCP、序列化等实现名只出现在开发文档，不进入普通操作提示。首版“复制”明确为独立副本，不出现尚未实现的共享引用入口。

新增组件或调整主题时，先更新配色文档的角色契约或本文的组件契约，再更新实现与验收证据。规格只引用本文，不复制另一套色值。交付说明必须区分“文档已规定”“源码已实现”“画面已验收”。局部例外记录用途、影响范围和复核条件，不能成为第二套未经说明的规范。

## 7. 已知差异与待核对项

| 项目 | 证据与边界 | 处理 |
| --- | --- | --- |
| 浅色目标迁移 | 已接入 Latte 与旧 light 设置映射 | 内置切换已验证，完整 U1 仍待人工验收 |

| 舞台文本菜单 | TextNode 菜单已接入统一色板与 15 字号 | Latte 颜色断言通过，布局与缩放继续按 U2 验收 |
| 字体、工具栏与图标 | 本轮未读取场景和主题资源 | 不给出全局风格已统一的结论 |

## 8. 手动一致性验收

完整人工验收待执行；已授权的自动检查及运行截图见 [主题验证记录](../validation/theme-palette.md)，不代表 U1–U6 全部通过。

| 编号 | 如何触发 | 应观察到的结果 | 失败时重点检查 |
| --- | --- | --- | --- |
| U1 | 分别启用深色、浅色、跟随系统；切换前后打开设置、属性、菜单及新详情面板 | 各区域使用对应角色；后打开窗口无旧配色；用户自定义颜色保留 | 局部 override、弹窗主题同步、默认值与自定义值混淆 |
| U2 | 在 100%、150%、200% UI 缩放下查看上述组件，并输入长中文和长路径 | 文本可读、按钮可达、无裁切重叠；画布缩放不改变界面字号 | 重复缩放、固定尺寸、字体回退、布局最小尺寸 |
| U3 | 只用键盘遍历表单、列表、标签页、按钮，测试正常/悬停/选中/禁用/只读 | 焦点始终可见；状态有明确差异；关闭窗口返回入口 | 透明 focus 样式、焦点顺序、状态样式缺项 |
| U4 | 中文组合输入时确认/取消，随后确认/取消详情编辑 | 选词不触发画布操作；提交和取消与首版规格一致 | IME 状态、事件传播、双重提交 |
| U5 | 连续切换主题、快速开关弹窗、调整窗口尺寸，再关闭动效重复 | 最后状态准确，无旧遮罩、错色或不可见输入层；关闭动效立即完成状态切换 | 动画取消、输入禁用恢复、effects 调用链 |
| U6 | 对照同一命令的菜单、工具栏、属性入口，触发空搜索及保存失败 | 名称、图标、快捷键及反馈含义一致；错误不冒充成功 | 多处命令文案、图标映射、错误状态处理 |

验收记录沿用 [首版验收格式](../validation/first-release.md)。截屏对照需记录主题、系统缩放、UI 缩放、窗口尺寸和代码版本；未获得运行授权前不生成伪造的验收截图。
