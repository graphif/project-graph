# 连续圆角

## 实现选择

统一节点、菜单、Dock 与弹窗的曲线风格，保留原生 Control、Theme、焦点和输入处理。

- `StyleBoxFlat`：适合普通圆弧和细线；`corner_detail` 只控制细分，不提供连续曲率形状。
- `ColorRect + Shader`：适合独立背景，但不能直接覆盖原生菜单样式，也不自动裁剪子节点。示例中的隐式函数并非精确距离场，不能直接用于等宽描边。
- 采用 Godot 自带 `StyleBoxTexture + DPITexture`：通过 SVG 曲线与描边生成九宫格样式，复用引擎的布局、栅格化、主题缩放和描边实现。无需第三方依赖。保留源 StyleBoxFlat 参数供换色和读取，不直接调用底层绘制 API。

每个角用两段对称三次贝塞尔曲线近似连续圆角；直线连接处曲率为零，角部中点切线与曲率连续。这是项目自己的近似轮廓，不宣称复现 Apple 私有公式。选中框和拖拽预览采样同一条曲线。

画布节点和分组与菜单共用 DPITexture。相机按实际屏幕缩放选择二次幂采样档位，避免固定 50 倍栅格化造成首次绘制停顿和缩小时过窄的边缘过渡；连线文字仍使用带 mipmap 的 ImageTexture。见[画布抗锯齿](canvas-antialiasing.md)。

## 尺寸规则

| 用途 | 圆角区域（逻辑像素） |
| --- | ---: |
| 按钮、输入框、菜单项、连线文字 | 12 |
| 列表面板 | 18 |
| 节点、分组、菜单外框、Dock、弹窗 | 24（节点和分组按实际尺寸限制） |

零圆角的分隔线、页签下划线和细滚动条保持原本用途。九宫格保留原有内容边距；圆角不改变文档数据。当前小型 UI 控件沿用原生圆弧，画布节点始终使用连续曲线。节点圆角取 `floor(min(24, max(0, min(width, height) / 2 - 3)))`，为一单位边框及四单位中间直线区留出空间；不得依赖九宫格在尺寸不足时自动收缩。填色、边框和阴影共用轮廓；节点边框仍使用自动对比灰度。

节点与分组在实际 Control 尺寸改变后更新圆角，不以颜色缓存或布局完成前的最小尺寸作为依据。选中轮廓读取当前可见背景的半径。透明文字输入层保留原生 StyleBoxFlat 的内容边距，不生成无可见内容的圆角贴图。

节点和分组的边框为 1 个世界单位。此前 24 单位圆角版本的回归记录覆盖 0.5、1、4、20、50 倍缩放；20 倍放大时，限定弧线区域的半透明过渡像素由 389 增至 1190。该历史计数不代表本次修复已验收，也不代表跨设备观感保证。

## 手动验收

1. 新建节点及嵌套分组，选中、拖动、双击编辑；背景、边框、选中与拖拽预览应贴合，编辑时文字不跳位。
2. 打开文件菜单、设置、命令面板及文件 Dock；观察四角，不应出现方形底色、黑色碎角或文字被裁切。
3. 切换 Mocha / Latte，调整界面缩放与画布缩放；确认边框等宽、焦点可见、颜色正确，没有明显锯齿或发虚。
4. 特别检查小尺寸按钮、长菜单与滚动列表，确保圆角不会挤掉内容或改变点击行为。

## 本次断口修复与验证

用户截图显示普通节点左右下圆角与直边接合处断开，而较大的分组边框完整。源码发现圆角按旧最小尺寸生成，文字或分组尺寸变化未同步更新样式；九宫格对向切边超出绘制尺寸时会失去连续的中间区。修复继续复用 Godot 自带 StyleBoxTexture、DPITexture 和现有曲线，仅补尺寸适配，不新增依赖或绘制框架。原生 StyleBoxFlat 不表达现有连续曲线；独立 shader 会增加主题及渲染集成，故不采用。

恢复工作区曾放大的 16／26／36 预设为原有的 12／18／24。36 单位预设在底部短工具栏上也出现接缝；恢复后已查看的浅色截图中接缝消失。

用户另行授权后，Godot 4.8.dev6 下圆角回归在 headless 和 X11 均通过；节点边框、分组透明度检查通过，`git diff --check` 通过。已补回归断言：短文本、多行、字号和分组尺寸变化后，九宫格横纵切边均保留中间区，且选中轮廓与背景半径一致。X11 生成深浅主题 50%／100%／200% 截图，人工读取截图确认普通节点边框连续。尚未执行跨平台打包、高 DPI 真机及用户原文件验收。

扩大检查发现 `canvas_text_focus_smoke` 在 headless 和 X11 失败，涉及单击取消全选、光标定位、插入文字及点击外部结束编辑。恢复本轮修改前的三个脚本后，X11 对照也出现上述失败及其他点击失败，确认工作区原先已存在此类问题；本次不将文本交互测试记为通过。

人工复核：打开截图对应图，分别在 50%、100%、200%、400% 画布缩放下观察 Project Graph、Waya 节点左右下角；再修改短文本、多行、字号及分组成员位置。预期直边与圆角连续、没有横向错台，选中轮廓贴合。若失败，记录缩放和节点内容，重点检查左右下角断口以及改字或切换主题后是否才恢复。测试入口：`godot --path . --script res://tests/continuous_corners_smoke.gd`。
