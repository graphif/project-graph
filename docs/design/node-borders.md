# 自动节点边框

节点与分组边框使用中性灰度，按画布、祖先容器和自身填色合成后的背景计算对比度，复用 `theme_palette.gd` 的灰度选择函数。不新增依赖。

边框颜色不再作为可编辑属性；旧 `border_color` 与 `use_theme_border` 保留存储兼容，但不覆盖自动显示颜色。颜色变化及容器层级变化会刷新边框，文档中的原始填色不变。

手动验证：在深浅主题分别创建透明子节点，将父分组填色改为黑、白、蓝、半透明粉色。子节点边框应保持中性灰且清楚可见；更换父分组后应刷新。打开节点详情和 Inspector，不应出现可编辑的边框颜色。若边框不更新，重点检查包含关系变化和祖先透明色合成。

当前工作区的 `tests/node_border_smoke.gd` 已通过；尚需真实复杂重叠布局的人工检查。本规则按包含关系合成背景，不采样无关对象的任意遮挡。
