# 连线箭头

箭头复用场景中的 Polygon2D，线身复用 Line2D，碰撞复用 ConcavePolygonShape2D。沿用 Godot Vector2.bezier_interpolate 和 Geometry2D 点入多边形判断；无需第三方几何库，也不引入底层绘制或自定义 shader。通用贝塞尔求值由引擎承担，本项目仅适配节点端口和箭头尺寸。

## 几何规则

- 箭头朝向目标边内法线，不从离散曲线末段或裁剪后的弦推算。同一端口、同线宽的常规长连线使用重合的三角形，避免多个倾斜箭头叠成尖刺。
- 长度为 `min(max(6, 3 * 线宽 + 2), 0.45 * 端口法向间距)`，半宽为长度的 0.4 倍，均为世界单位。法向间距不超过 1 时暂时隐藏箭头，分离后恢复。
- 贝塞尔终点移到箭头底边中心，并在该处保持法向切线。线身不再按弧长裁剪后强行扭转末端。碰撞中心线继续延伸至尖端，箭头内部参与点击距离判断。
- 方向、长度和派生曲线不写入文档；对象引用、注册类型及历史事务不变。不同线宽或不同剩余间距的箭头允许尺寸不同，不承诺合并成一个持久对象。

## 验证

2026-09-29：Godot 4.8.dev6 的 `arrow_geometry_smoke.gd` 通过 headless 与 X11 检查；补充四个入边方向、线宽 1／2／12 的断言后，X11 检查通过。同一回归在修改前代码上失败，覆盖汇入箭头叠刺、缩放改变世界几何、短线长度及重叠处理。

`edge_caption_smoke.gd`、`edge_contrast_smoke.gd` 在 X11 通过，包括连线文字、保存加载、撤销重做、端点移动和配色。已生成并查看 200% 汇入截图；50%／100% 截图同时生成。用户原文件、高 DPI 真机和跨平台导出尚未验证。

手动复核：从上下两个节点分别连入同一目标节点，放大观察汇入处；应只有整齐的箭头轮廓、线身无折角。移动源和目标到四个方向，再拉近至重叠并分开；应无反向大箭头，分开后恢复。保存加载、撤销重做和删除端点后，连接引用应正确，无残留箭头。若失败，重点检查端口方向、线身底边连接、碰撞命中及对象引用恢复。

原生 API 参考：[Vector2](https://docs.godotengine.org/en/stable/classes/class_vector2.html)。
