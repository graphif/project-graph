# 连线箭头

箭头复用场景中的 Polygon2D，线身复用 Line2D，碰撞复用 ConcavePolygonShape2D。沿用 Godot Vector2.bezier_interpolate 和 Geometry2D 点入多边形判断；无需第三方几何库，也不引入底层绘制或自定义 shader。通用贝塞尔求值由引擎承担，本项目仅适配节点端口和箭头尺寸。

## 几何规则

- 连接点由两节点中心方向与可见圆角轮廓求交，沿轮廓自由移动，不再跳选四边中点。复用 Geometry2D.segment_intersects_segment，按尺寸缓存轮廓；法线在相邻采样段之间插值，避免圆角处箭头逐段跳转。
- 箭头朝向目标轮廓内法线，不从离散曲线末段或裁剪后的弦推算。不同来向自然分布到不同落点；同端口、同线宽的常规长连线仍使用重合三角形。
- 长度为 `min(max(6, 3 * 线宽 + 2), 0.45 * 端口法向间距)`，半宽为长度的 0.4 倍，均为世界单位。法向间距不超过 1 时暂时隐藏箭头，分离后恢复。
- 贝塞尔终点移到箭头底边中心，并在该处保持法向切线。线身不再按弧长裁剪后强行扭转末端。碰撞中心线继续延伸至尖端，箭头内部参与点击距离判断。
- 拖拽预览与正式连线共用端点算法，高亮标记实际连接点。中心连线方向上的可见间距在 0–12 世界单位内平滑淡入淡出，防止穿过重叠中心时露出反向短线；完全淡出的线不参与距离命中。
- 方向、长度和派生曲线不写入文档；对象引用、注册类型及历史事务不变。不同线宽或不同剩余间距的箭头允许尺寸不同，不承诺合并成一个持久对象。

## 验证

2026-09-29：Godot 4.8.dev6 的 `arrow_geometry_smoke.gd` 通过 headless 与 X11 检查，覆盖四个入边方向、线宽 1／2／12、缩放、短线、重叠和删除端点。自由端点更新后，增加不同来向落点分离及预览/高亮与正式端点一致断言。

`connection_continuity_smoke.gd` 用 3601 个连续位置环绕目标一圈，检查端点、轮廓法线和整条曲线的逐步位移。旧四边中点算法出现端点及整线跳变，新算法通过。

`edge_caption_smoke.gd`、`edge_contrast_smoke.gd` 在 X11 通过，包括连线文字、保存加载、撤销重做、端点移动和配色。已生成并查看 200% 汇入截图；50%／100% 截图同时生成。用户原文件、高 DPI 真机和跨平台导出尚未验证。

手动复核：从上下两个节点分别连入同一目标节点，放大观察汇入处；应有分开的整齐箭头轮廓、线身无折角。拖动源节点绕目标一圈，连接点应沿圆角连续滑动；再拉近至重叠并分开，应平滑淡出/恢复，无反向大箭头。保存加载、撤销重做和删除端点后，连接引用应正确，无残留箭头。若失败，重点检查圆角附近跳变、预览与落点不一致、线身底边连接及对象引用恢复。

原生 API 参考：[Vector2](https://docs.godotengine.org/en/stable/classes/class_vector2.html)。
