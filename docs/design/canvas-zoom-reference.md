# 画布缩放基准

画布以 Camera2D 实际倍率 2.0 作为界面 100%，即原先 200% 的视觉大小。新建标签页和“重置缩放”均使用此基准；状态栏统一按 `实际倍率 / 2 * 100` 显示。

复用已有 Camera2D 缩放、输入锚点和平滑处理，不引入依赖。物理坐标、缩放上下限、SVG 采样、适合窗口计算及 PNG 导出继续使用实际倍率。文档仍保存实际倍率，因此旧文件打开后保持原视野，只改变百分比显示。

验证：`canvas_zoom_reference_smoke.gd` 覆盖新建、重置命令、状态栏、新标签页及倍率保存加载；`pinch_zoom_smoke.gd` 覆盖手势仅应用一次。用户原文件与跨平台尚需人工验证。

人工复核：新建画布应显示 100%，视觉大小等同原先 200%；放大后执行重置应回到新基准。保存再打开应保持原视野。若失败，检查状态栏与实际大小是否一致、文件加载是否重复乘二、手势是否重复触发。
