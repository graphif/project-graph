# 同色容器的层级不透明度

最内层为第 1 层。同 RGB 的连续包含链向外逐层乘 0.78：

| 示例 | 层级 | 填充不透明度倍率 |
| --- | --- | --- |
| 计划01 | 1 | 100% |
| Project Graph | 2 | 78% |
| 计划02 | 3 | 60.84% |
| Waya | 4 | 47.4552% |

实际填充 alpha = 用户设置的 alpha × 0.78^(层级−1)。不同 RGB 中断链；多个子分支取最长连续同色链。空间包含关系决定层级，普通连线和主题父引用不参与。

复用现有自内向外容器布局，以及 Godot Color、pow 和 StyleBoxFlat；无第三方依赖。仅派生显示填充，不改变保存的 fill_color，不淡化文字或边框。透明填充按正常绘制顺序与下方容器合成。

本轮通过 Godot MCP 脚本读取/修改及编辑器脚本启动独立测试进程。container_opacity_smoke 在 headless 和图形模式通过，检查四层数值、实际 StyleBox alpha、原始颜色保留、异色中断、自定义 alpha 和重新包含。图形截图已检查。

手动验证：将图中四个节点设为同一蓝色，最内层应实、越外层越淡；改中间节点颜色，或将最内节点移出再移回，应立即重算。若不符，检查是否存在真实包含关系、是否运行了旧实例，以及文字/边框是否被错误地一起淡化。真实鼠标操作、存档重开和跨平台显示尚未手测。
