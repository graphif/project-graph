# 节点编辑轮廓

主窗口通过 SubViewportContainer 转交鼠标事件时会短暂释放编辑焦点。focus_exited 不再立即关闭编辑器，而是延迟到焦点转交结束后重新确认；重新获得焦点则继续编辑。回归从根窗口发送鼠标移动、按下、松开及文字事件，覆盖双击全选、点击中间插入、50%/100%/200% 缩放和点击框外退出。直接调用子视口 push_input 无法覆盖这一焦点转交流程。

编辑时单击文字取消全选，并使用 Godot TextEdit 原生字形命中定位光标。关闭 drag_and_drop_selection_enabled，避免单击已有选区进入文本拖放。双击全选后，点击句子中间再输入，应只在点击处插入，保留其余文字；重点检查缩放后的光标偏移。自动回归覆盖 50%、100%、200% 缩放的完整鼠标按下、松开及字符插入。

第一次双击节点进入编辑并默认全选文字；编辑状态下再次双击输入区，调用 TextEdit.select_all() 全选整个节点文本，并保留键盘焦点。手动验证时可输入两行文字，再次双击后应两行全部选中，继续打字应替换全部选区。

全选延迟到当前 GUI 输入处理完成后执行，避免被 TextEdit 自带选词覆盖。点击外部退出编辑使用事件自身坐标转换到编辑框局部坐标，避免依赖可能滞后的全局鼠标位置。回归通过 SubViewport.push_input 发送双击按下及松开，覆盖英文多词、中文、多行及已有局部选区；不再仅发射 gui_input 信号。手动重点检查松开鼠标后是否仍全选，以及点击框外是否正常退出；真实输入法组合输入仍待人工验证。

进入编辑时继续由 Label / ContainerPanel 绘制原来的节点背景和轮廓，仅将边框切换为焦点色。TextEdit 背景和边框透明，可以为光标和输入法测量扩展，不再绘制第二个尺寸不同的框。复用现有 Godot 控件和样式，无新依赖。

手动验证：建立带连线的普通节点及嵌套分组，在 100%、200% 缩放下双击文字。进入编辑前后轮廓位置、尺寸及连线锚点应一致，只有边框颜色变化。按左右键应移动光标；Esc 取消后恢复原文字。重点检查双重边框、尺寸突变、文字重影及连线偏移。真实输入法预编辑和不同 DPI 仍需人工检查。
