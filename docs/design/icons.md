# 图标选型与使用规范

状态：2026-09-29，推荐继续以 Lucide 为主图标库。已有菜单映射在源码中确认，尚未完成全部资源审计或视觉验收；本轮不安装、替换或生成图标资源。

## 1. 选型

| 候选 | 适用性 | 本项目选择 |
| --- | --- | --- |
| [Lucide](https://lucide.dev/) | 可调整颜色、尺寸和线宽，线性风格适合紧凑编辑器 | 首选；main 已有菜单映射，优先复用现有资源 |
| [Phosphor](https://github.com/phosphor-icons/core) | SVG 按不同字重提供，适合需要多种视觉重量的界面；MIT | 备选；当前没有替换整套图标的明确收益 |
| [Tabler](https://tabler.io/icons) | 24×24 网格、2px 描边的线性图标；MIT | 备选；与当前主库用途重叠，不混装 |

Lucide 官方 [许可说明](https://lucide.dev/license) 包含 ISC，以及 Feather 派生图标对应的 MIT 声明。正式分发保留所用版本完整许可与版权信息，不把所有资源简单标为只有 ISC。本轮未确认仓库图标的精确来源版本、哈希或许可证完整性，UI0 中补齐。

## 2. 视觉与主题契约

同一操作在菜单、工具栏、右键菜单和命令面板使用同一语义图标。菜单维持现有 18 逻辑像素基线；工具栏推荐 20、独立大入口可用 24，属于待落地规则。遵循图标原始 viewBox 与比例，禁止单独拉伸或任意加粗某一个图标。命中区域由按钮布局负责，不等于可见图标尺寸。

默认使用统一线性样式。普通、次要、禁用、活动状态分别取 [配色文档](color-system.md) 的 icon.default / icon.muted / icon.disabled / icon.active。强调按钮内图标取 text.on_accent，与按钮文字一致。选中同时使用背景或轮廓，不仅改变图标颜色。

主题插件只更换颜色角色，默认不更换图标几何、不另存一套浅色 SVG。图标包扩展若未来需要支持，应另定资源清单与语义映射契约，不能混入颜色预设 schema。

图标按钮提供中文提示、可见焦点与明确可访问名称。错误提示保留文字。箭头、撤销/重做等方向图标不随意镜像；品牌标志、用户附件缩略图和原生窗口控制不强制改造成 Lucide。

## 3. 命令映射

前半部分取自已读 main 的 MENU_ICON_FILES；“建议”项需实施时核对所固定版本确有该 SVG，不表示资源已安装。

| 操作 / 语义 | Lucide 名称 | 证据 |
| --- | --- | --- |
| 新建 | plus | 已有 newDraft 映射 |
| 打开文件 | file | 已有 openFile 映射 |
| 打开文件夹 | folder-open | 已有 openFolder 映射 |
| 搜索 | search | 已有 quickOpen / Search 映射 |
| 最近文件 | clock | 已有 recentFilesSub 映射 |
| 保存 | save | 已有 saveFile 映射 |
| 撤销 / 重做 | undo / redo | 已有 Undo / Redo 映射 |
| 删除文件 | trash-2 | 已有 deleteFile 映射 |
| 导出 | download | 已有 exportSub 映射 |
| 设置 | settings | 已有设置映射 |
| 配色 | palette | 已有 Palette / helpThemes 映射 |
| 创建分组 | blocks | 已有 groupSelection 映射 |
| 帮助 / 缺失回退 | circle-help | 已有回退映射 |
| 新详情入口 | file-text | 建议复用已使用的图标 |
| 打开来源 | external-link | 建议复用已使用的图标 |
| 来源摘录 | quote | 建议，资源待核对 |
| 建立连线 | link-2 | 建议，资源待核对 |

运行时保持稳定命令 ID→图标名映射，不能由翻译后的菜单文字推测图标。不存在的映射在开发检查中报告，界面保留文字和回退图标，不能导致整个菜单构建失败。

## 4. 复用与交付

先审计当前实际引用、资源版本、重复文件与许可；目录存在不代表正在使用。保持第三方资源只读，未经明确授权不改写第三方目录。补充图标应从确定版本选取原始 SVG，记录来源 URL、版本/提交、SHA-256 和许可，不手工重绘已有通用图标，不用 AI PNG 替代 UI 图标。

Godot 集成复用现有图标加载与 Theme 接口；按颜色、尺寸及资源标识隔离缓存。SVG 的 currentColor 不假定自动继承，显式着色策略见配色文档。所有项目图标资源操作通过 Godot MCP；新版本 Godot、导出平台及高 DPI 显示需要实际验证。

## 5. 手动验收（未执行）

| 操作 | 预期 | 失败重点 |
| --- | --- | --- |
| 对照菜单、工具栏及命令面板的同一命令 | 形状、含义、文案一致 | 分散映射、同名异义 |

| 在 100%、150%、200% 缩放下观察线条 | 边缘清晰，比例一致，不裁切，点击区域足够 | 重复缩放、纹理导入、固定最小尺寸 |
| 键盘聚焦并切换禁用/选中状态 | 焦点清晰，状态可辨，提示和文字仍可理解 | 单靠颜色、缺失状态、不可访问图标按钮 |
| 使用受控缺失映射样例 | 显示回退图标与原命令文字，记录缺失 | 静默空白、菜单构建失败 |
