# 节点编辑交互

状态：2026-09-29 用户确认，代码已接入当前工作区；行为函数自动检查通过，真实键盘/鼠标/IME 尚待手动验证。参考用户指定的 XMind 操作习惯；以下是本项目约定，不声称逐项复制其所有版本行为。

| 输入 | 行为 |
| --- | --- |
| 单击 | 选中；点击已选节点保留多选，便于一起拖动 |
| Shift + 单击 | 追加到多选；再点已选节点仍保留选中 |
| Ctrl 或 Cmd + 单击 | 只选当前节点，清除其他选择；优先于 Shift |
| 双击 / F2 | 选中该节点并编辑正文 |
| 未编辑时 Tab | 新建子主题并进入编辑 |
| 未编辑时 Enter | 新建同级主题；无主题父节点时创建另一个根主题 |
| 编辑时 Enter / Shift+Enter | 确认 / 换行 |
| 编辑时 Esc | 放弃本次文字改动 |
| 手势中 Esc | 取消框选、连线、切割、画笔或拖动；空闲时清除选区 |
| Delete | 空闲时删除对象；文字编辑时交给编辑框 |
| Ctrl/Cmd+Z | 编辑时为文字撤销，画布操作为事务撤销 |

主题父节点由 TextNode.topic_parent 独立保存，与空间 container 和普通连线分离。Tab/Enter 创建的主题记录父引用，缩进导入记录显式层级；旧文件缺少字段时视为根主题，不通过旧连线猜测父节点。普通连线新增、反转或删除不改主题父关系。删除主题父节点时，未被空间包含级联删除的子主题变为根主题。复制仅在复制范围内重建父引用；复制单个子主题成为独立根节点。

节点草稿允许扩展，达到宽度限制后软换行，确认时才修改正文；Esc 保留原正文。组合输入和刚提交的中文候选优先于节点快捷键。输入法候选窗口位置尚未运行复现，不能宣称已修复所有平台定位。

取消手势使用既有历史快照恢复，取消不应增加撤销或清空重做。框选取消恢复之前的选择，拖动取消恢复整个事务中受影响对象的位置。生成节点与后续编辑为可区分操作；既有历史稳定等待机制保留。

## 待用户手动验证

1. 选中 A，Tab 输入 B，Enter 确认；再 Enter 输入 C。B/C 应同属 A；额外连到 B 的普通连线不改变结果。
2. 选中无父节点 A，Enter 应生成独立根主题；旧文件也不根据来向连线猜父节点。
3. 在小节点输入长中文，Shift+Enter 换行、Enter 选词再确认；预编辑不得触发新节点或相机移动，Esc 放弃应恢复原文。失败重点检查 IME 提交时序、焦点和 TextEdit 尺寸。
4. 多选拖动、画笔、框选时按 Esc，随后松开鼠标；对象与选择按上述规则恢复，不产生新历史；再尝试撤销/重做，检查是否误取消上一次已完成操作。
5. 保存重开、复制父子节点、只复制子节点、删除父节点后撤销；检查父引用、独立副本、空间包含与连线是否混淆。

本轮复用 Godot TextEdit、现有 AutoSizeTextEdit、导出属性/引用恢复、History 和舞台节点；无新第三方依赖。使用 Godot MCP 脚本读取/修改工具，已运行主题、显示和基础交互检查；History 取消 API 已独立提交，其他节点交互集成仍依赖未提交的工作区改动，见 [验证记录](../validation/basic-interaction.md)。
